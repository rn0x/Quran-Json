🚀 أمثلة سريعة لاستخدام API

جرب هذه الأمثلة لبدء استخدام API القرآن الكريم:

📖 جلب جميع السور

GET /api/surahs

احصل على قائمة جميع السور مع معلوماتها الأساسية

📜 سورة محددة

GET /api/surah/1

احصل على بيانات كاملة لسورة محددة مع جميع آياتها

🔍 آية محددة

GET /api/verse/1/1

جلب بيانات آية محددة (رقم السورة/رقم الآية)

� ملفات صوتية السورة

GET /api/audio/1

روابط التسجيلات الصوتية للسور من المكتبة العامة لكل قارئ متاح.

👥 جميع القراء الصوتيين

GET /api/reciters

قائمة شاملة بجميع القراء الصوتيين (158 قارئ)

🎧 ملفات صوتية

GET /api/audio/1

روابط التسجيلات الصوتية للسور (158 قارئ)

🕌 آيات السجدة

GET /api/sajda

جميع آيات السجدة في القرآن الكريم (15 سجدة)

📄 صفحة القرآن

GET /api/pages/2/1

معلومات صفحة القرآن لآية محددة (604 صفحة)

📚 جزء من القرآن

GET /api/juz/1

معلومات جزء محدد من القرآن (30 جزء)

🖼️ صور صفحات القرآن

GET /data/quran_image/1.png

صور عالية الجودة لصفحات المصحف الشريف

📋 مرجع API

GET /api/api-reference

مرجع شامل لجميع endpoints والإحصائيات

🎙️ قراء آية-بآية

GET /api/ayah-audio/reciters

قراء ملف ayahBayah.json مع روابط الجودات المتاحة

🎧 صوت آية واحدة

GET /api/ayah-audio/1/1/1?bitrate=32

يبني رابط MP3 لآية محددة مثل 001001.mp3

🖼️ صور القراء مع IDs

GET /api/reciter-images

يربط ID القارئ مباشرة برقم الصورة، مثال: 68 ← 068-عبدالرحمن السديس.jpg.

🕌 صور أسماء السور

GET /api/surah-names

يعيد أسماء السور وروابط SVG من data/suwer-name، مثل /data/suwer-name/001.svg.

🎙️ قراء التتبع آية بآية

GET /api/ayah-bayah/reciters

قائمة القراء المتاح لهم Surah-by-Surah أو Ayah-by-Ayah مع عدد السور والآيات والتوقيتات.

👤 تفاصيل قارئ التتبع

GET /api/ayah-bayah/reciter/68

مثال عبدالرحمن السديس (ID 68): بيانات القارئ، الصورة، نوع التسجيل والسور المتاحة.

▶️ سورة كاملة مع التتبع

GET /api/ayah-bayah/68/1

مثال الفاتحة بصوت السديس: رابط تسجيل السورة وتوقيت كل آية/كلمة حسب نوع المصدر.

⏱️ آية محددة مع توقيتها

GET /api/ayah-bayah/68/1/1

مثال الآية 1 من الفاتحة: يرجع timestamp أو audio_url وword segments لتفعيل التتبع أثناء التشغيل.

📘 أمثلة القراء والصور والتتبع آية بآية موجودة الآن داخل وثائق OpenAPI/ReDoc بالأسفل، ضمن مجموعة «القراء والصور والتتبع آية بآية». افتح أي endpoint لرؤية Response samples والأمثلة الحقيقية للسديس والمنشاوي والشريم.
